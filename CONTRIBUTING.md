# Contributing to CISA MCQ Project

## Getting Started
1.  **Clone the repo**:
    ```bash
    git clone https://github.com/nw48mbvhh9-cyber/CISA-MCQ.git
    ```
2.  **Navigate to the directory**:
    ```bash
    cd CISA-MCQ
    ```

## Development Workflow
To avoid overwriting each other's work, please follow this flow:

### 1. Get the latest changes
**Always** pull the latest code before you start editing any files.
```bash
git pull origin main
```

### 2. Make your changes
Edit the files as needed.

### 3. Save (Commit) your changes
```bash
git add .
git commit -m "Describe your changes here"
```

### 4. Share (Push) your changes
```bash
git push origin main
```

## Troubleshooting
If `git push` fails, it usually means someone else updated the code while you were working.
1.  Run `git pull origin main` to get their changes.
2.  Fix any conflicts if Git reports them.
3.  Run `git push origin main` again.
